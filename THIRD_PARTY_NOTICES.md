# Composants embarqués

BSC Radio Studio : AGPL-3.0-or-later. Voir LICENSE et UPSTREAM.md.

L’application embarque Python (PSF), PySide6 / Qt (LGPLv3/GPLv3, bibliothèques dynamiques),
HTTPX (BSD), PyYAML (MIT), feedparser (BSD), trafilatura (Apache-2.0),
python-dotenv (BSD), websocket-client (Apache-2.0), packaging (Apache-2.0/BSD),
imageio-ffmpeg (BSD) et leurs dépendances. Les métadonnées et notices disponibles
dans les distributions sont conservées par la chaîne de compilation.

Le binaire FFmpeg fourni par imageio-ffmpeg utilise les licences indiquées par
ce fournisseur ; consulter https://github.com/imageio/imageio-ffmpeg et
https://ffmpeg.org/legal.html pour ses sources et sa configuration de compilation.

PyInstaller est un outil de compilation sous GPL avec exception de distribution.
Inno Setup est un outil de compilation externe : https://jrsoftware.org/.

Sources complètes de l’application et historique des versions :
https://github.com/colonelchaboumm/BSC-radio
